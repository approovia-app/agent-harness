# Reviews

Milestone review findings and their resolution. Reviewers append findings. The implementing agent updates only the status and fixing commit of each finding — never the finding text itself.

## Format

```text
### Review: M<n> — <YYYY-MM-DD>
Reviewer: <fresh session / maintainer>
Scope: <files reviewed or "see diff <start>..<end>">

#### Finding R-<nnn>: <short title>
- Severity: Critical | Major | Minor | Nitpick
- File: <path>:<line>
- Description: <what is wrong and why it matters>
- Suggested fix: <concrete — what to change>
- Status: open | fixed in <short commit hash> | accepted (<reason>)
```
